# On-Road Vehicle Breakdown Assistance (ORVBA)

## Overview

On-Road Vehicle Breakdown Assistance (ORVBA) is a web-based platform designed to help vehicle owners quickly find assistance during vehicle breakdowns. The system connects users with nearby service providers and businesses that can offer support such as fuel delivery, battery assistance, tire repair, and mechanical services.

## Features

### User Module

* User Registration
* User Login
* User Dashboard
* Breakdown Assistance Request
* Location-Based Service Request
* Contact Support

### Business Module

* Business Registration
* Business Login
* Service Management
* Customer Assistance Requests

### Admin Module

* Admin Login
* System Monitoring
* User and Business Management

## Installation Steps

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place the project folder inside:

```text
C:\xampp\htdocs\
```

4. Open phpMyAdmin:

```text
http://localhost/phpmyadmin
```

5. Create the required databases and tables.
6. Open the project using:

```text
http://localhost/ORVBA/HTML/StartingPage.html
```
